# Plantilla de Biografía MD3

Archivos:

- `index.html`: estructura y contenido.
- `styles.css`: diseño Material Design 3 y responsive.
- `script.js`: menú móvil, tema claro/oscuro y navegación activa.

## Cómo usar

1. Abre `index.html` en Visual Studio Code.
2. Ejecuta el archivo con Live Server.
3. Cambia los textos de ejemplo.
4. Sustituye las URLs de imágenes por tus propias imágenes.

Si quieres usar imágenes locales, crea una carpeta:

assets/images/

Y luego usa, por ejemplo:

<img src="assets/images/perfil.jpg" alt="Foto de perfil">

La plantilla no necesita Bootstrap.
